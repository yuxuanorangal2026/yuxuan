快速上手

四个步骤即可完成：安装 → 修补 → 签名 → 刷入。每一步的「必须」项缺一不可。

安装 OrangalSu 必须

在 T20 上安装 OrangalSu-2.2.0.apk（minSdk 28，即 Android 9）。首次打开授予必要权限，确认守护进程状态为在线。

验证：App 首页显示「守护进程在线」

修补 boot 镜像 必须

在 App 的修补页选择工作模式（越狱 / Magisk 集成 / 免刷机提权），输入原厂 boot.img。magisk 模式下自动装入 stub.xz（OrangalSu 壳）与 tinyinit。

注意：产物必须保持整 35MB（36,700,160B）

AVB 签名 必须

在修补模式中选择「添加 AVB 签名」。签名使用 SHA256_RSA4096，写入标准 HAS0 描述符（digest 位置、image_size 与镜像内容自洽）。

验证：vbmeta footer 存在，digest 与镜像匹配

刷入 boot 分区 必须

将签名后的镜像刷入 boot 分区，重启。

fastboot flash boot boot_signed.img
展讯 T20 亦可使用展讯下载工具烧录
WORK MODES

三种工作模式

越狱优先、Magisk 兼容、免刷机兜底——按你的需求选一种，互斥可选。

模式原理权限要求
越狱模式 cmdline 注入 androidboot.selinux=permissive，ramdisk 由 tinyinit 挂载 system 分区并 pivot_root 后移交系统 init；不运行任何 root 守护进程。 无需 root
Magisk 集成 magiskinit 引导 + stub.xz（OrangalSu 壳）随 boot 刷入，开机自动安装 OrangalSu 作为管理器。 刷机一次
免刷机提权 利用 CVE-2024-31317（ZygoteProcess 不安全反序列化）以任意应用身份执行代码，覆盖 Android 9–13；App 内一键检测与部署。 需 WRITE_SECURE_SETTINGS
FEATURES

为什么选择 OrangalSu

液态玻璃视觉、内核级能力与签名级正确性，围绕展讯 T20 打磨。

液态玻璃 UI

壁纸层毛玻璃 + 底栏半透明 blur，仪表盘与组件尺寸按触控密度收敛，对标 iOS 26 液态玻璃质感。

越狱模式

内核 Permissive 启动，不依赖任何 root 前置条件，tiniinit 自动挂载 system 并 pivot_root，行为贴近原厂 SAR。

免刷机提权

CVE-2024-31317 提权通道：Android 9–13 全系覆盖，不刷 boot 也能进入提权管理流程。

AVB 签名正确性

SHA256_RSA4096 + 标准 AvbHashDescriptor：digest 位于标准偏移、image_size 自洽、RSA 验签可通过，产物过启动校验。

Magisk 集成

stub.xz = OrangalSu 壳，随 boot 刷入后开机自动安装，root 权限由 OrangalSu 管理而非 Magisk。

展讯链路打磨

为 ud710_ctg30air / T20 定制：boot 整 35MB、page 2048、header v1、无 ramdisk 原厂镜像全适配。
